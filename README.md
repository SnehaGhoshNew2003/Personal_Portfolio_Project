# Sneha Ghosh - Portfolio Website

This is a personal portfolio website for **Sneha Ghosh**, showcasing skills, education, projects, and contact details. It is built using HTML, CSS, and JavaScript.

## Features
- **Responsive Design:** Adapts to various screen sizes using Bootstrap.
- **Dynamic Typing Effect:** Animated text effect in the hero section.
- **Interactive Navigation:** Hamburger menu for mobile-friendly navigation.
- **Skill Progress Visualization:** Circular progress bars display skill levels.
- **Projects Showcase:** Highlights key projects with GitHub links.
- **Contact Form:** Enables users to send messages.

## Technologies Used
- **HTML5** (Structure)
- **CSS3 & Bootstrap** (Styling & Layout)
- **JavaScript & jQuery** (Interactivity)
- **Font Awesome** (Icons)
- **Typed.js & Circle Progress** (Animations)

## Installation & Usage
1. Clone the repository:
```bash
git clone https://github.com/yourusername/portfolio.git
cd portfolio
```
2. Open `index.html` in a browser to view the portfolio.
3. Customize `style.css` and `script.js` as needed.

## Project Sections
- **Home:** Introduction with a dynamic typing effect.
- **About Me:** A brief summary of skills and interests.
- **Education:** Displays academic timeline.
- **Skills:** Circular progress indicators for proficiency levels.
- **Projects:** List of projects with GitHub links.
- **Contact:** Interactive form to reach out.
